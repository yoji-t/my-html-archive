GitHubでリポジトリ作成 追加方法

🚀 超簡単追加方法（30秒）

  1. articles/ フォルダに xxx.html を置く（今回作ったような単体HTMLでOK）
  2. data.json に1行追加するだけ：
{
  "id": "my-new-page",
  "title": "新しいページのタイトル",
  "file": "my-new-page.html",
  "date": "2026-10-02",
  "tags": ["競馬", "考察"],
  "summary": "一言要約"
}

あとは git add . && git commit -m "add article" && git push でGitHub Pagesに自動反映。Jekyll不要、ビルド不要。

GitHub Pages 公開手順

  1. このフォルダ一式をGitHubリポジトリにPush（リポジトリ名は username.github.io か任意）
  2. GitHub > Settings > Pages > Source: Deploy from a branch > Branch: main / root
  3. 数分後に https://username.github.io/xxx/ で公開
