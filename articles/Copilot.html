POWERPOINT × COPILOT

Copilotに
「自社っぽい資料」を
作らせる方法

プロンプトを細かくする前に見直したいのは、 Copilotに渡している「PowerPointテンプレート」です。

結論： 「どう作って」と説明するより、 「これが自社の資料です」と見本を見せる。
CORE MESSAGE

Copilotの資料が「AIっぽい」のは、 プロンプトの問題とは限りません。
まず見直したいのは、 テンプレートに入っている「見本スライド」です。

WHY?

資料が「AIっぽく」なる3つの原因

01

見本が入っていない

テンプレートに完成形の見本がないと、 Copilotが参考にできる情報が少なくなります。

02

白紙から作っている

会社のテンプレートを使わず、 白紙のPowerPointから作ると、 自社らしいデザインが伝わりにくくなります。

03

仮の文字を指示にしている

プレースホルダーの文字は、 Copilotへの指示として使うものではありません。 枠の位置・大きさなどが重要です。

THE KEY IDEA

言葉で説明するより、見本を見せる

BEFORE

プロンプトで細かく説明

「青を使ってください」
「タイトルは上部」
「本文は2段組」
「文字サイズは24pt」

毎回細かく説明する必要があります。

→
AFTER

完成形の見本を見せる

「このテンプレートの見本に 合わせて作ってください」

Copilotが参考にできる 具体的なデザインが最初からあります。

「どう作るか」を毎回説明するより、
「これがうちの資料」という実例を渡す。
TEMPLATE

テンプレートに入れる見本

理想的には、資料の流れに合わせて代表的なスライドを用意します。 ただし、最初から全部そろえる必要はありません。

表紙
目次・章扉
本文
データ・グラフ
タイムライン
プロセス図
引用・Q&A
まとめ・結論

※実際には、自社でよく使うスライドから 5枚程度を選ぶところから始めても十分です。

DESIGN RULES

見本を作るときのポイント

プレースホルダーを使う

テキストボックスではなく、 PowerPointのプレースホルダーを使って レイアウトを設計します。

テーマで統一する

色やフォントはスライドごとに設定するのではなく、 スライドマスターやテーマで統一します。

情報量の違いも見せる

余白の多いスライド、標準的なスライド、 情報量の多いスライドなどを用意します。

枠のサイズを適切にする

実際に入る文字量を想定して、 プレースホルダーの大きさを調整します。

装飾を重ねすぎない

文字や画像の場所に、 飾りの図形を重ねないようにします。

デスクトップ版で作る

テンプレート作成時は、 WindowsまたはMacのPowerPointを使います。

HOW TO START

テンプレートを作る4ステップ

1

過去の資料から見本を選ぶ

「自社らしい」と感じるスライドを、 よく使うパターンから選びます。 まずは5枚程度でもOKです。

2

1つのテンプレートにまとめる

プレースホルダーやテーマカラー、 フォントなどを整えて、 自社用のテンプレートとしてまとめます。

3

テンプレートを開いてからCopilotを使う

元ファイルを直接編集せず、 必要に応じて複製したテンプレートを開き、 その状態でCopilotに依頼します。

4

「条件」と「素材」を分けて渡す

資料の目的・読者・構成などの条件と、 数字・事実などの素材を分けて入力します。

PROMPT EXAMPLE

Copilotへの依頼例

テンプレートを開いた状態で、 「見本に合わせる」ことを明確にします。 

開いているテンプレートの見本スライドに合わせて、
次の資料を作ってください。

■資料の条件
①資料の種類：（例：月次の報告）
②読む人：（例：部長会の出席者）
③一番伝えたいこと：（1文で）
④章の順番：（章の名前を順に）

■素材
（数字と事実を箇条書きで貼る）

■守ること
①数字は素材に書いたものだけを使い、
  素材に無い数字は作らない
②素材から判断できない点は、
  最後のスライドに「確認が必要な点」として並べる
AI MODEL

AIモデルを変えるのは、そのあと

Copilotでは、環境によって複数のAIモデルを選択できる場合があります。

ただし、この記事の考え方では、 モデルを変更する前にテンプレートを整えることが先。

見本がない状態でモデルを変えるより、
まず「何を参考に作るか」を整える。
FINAL CHECK

Copilotが作った資料を出す前に確認する3つ

✓
1. 数字が合っているか 元の素材とスライドの数字を突き合わせる。
✓
2. 確認事項を埋めたか Copilotが判断できなかった項目を、 人間が確認して解決する。
✓
3. 外に出してよい情報か 社外秘の数字や不要な個人情報などが 混ざっていないか確認する。
THE TAKEAWAY

プロンプトを増やす前に、
「見本」を増やそう。

Copilotに自社らしい資料を作らせるために、 最初にやることはシンプルです。
