iPhone × Gyazo × Notion

Gyazoの画像をNotionに簡単保存する方法

Makeなどの外部自動化サービスを使わず、 iPhoneの「ショートカット」とNotion APIを使って、 Gyazoの画像をNotionで管理する方法を解説します。

結論

おすすめは、 Gyazo → iPhoneショートカット → Notion という構成です。

📸 Gyazoで撮影
→
📤 共有
→
⚡ ショートカット
→
📝 Notion

普段の操作は、 Gyazoで撮影 → 共有 → 「Gyazo → Notion」 だけにできます。

1. 今回の仕組み

単純にGyazoのURLをNotionへ貼り付けるだけではなく、 Notion APIを使って画像ブロックとして登録します。

Gyazo
→
iPhone
→
Notion API
→
画像ブロック

⚠️ 重要

今回はまず、 Gyazoの画像URLをNotionの画像ブロックとして表示する方式 を採用します。

そのため、MakeやZapierなどの外部自動化サービスは必要ありません。

2. Notionに「Gyazo Inbox」を作る

まずNotionに新しいデータベースを作成します。

データベース名

📥 Gyazo Inbox

おすすめプロパティ

プロパティ 種類
名前 タイトル
Gyazo URL URL
撮影日時 日付
ステータス セレクト

ステータスは、例えば以下で十分です。

  • 未整理
  • 保存
  • 不要

3. Notionの連携を作る

1
Notionの設定を開きます。
2
My connections / Connections を開きます。
3
Create new integration を選択します。
4
名前を Gyazo Shortcut などにします。

🔐 API Secretについて

作成するとNotionのIntegration Secretが発行されます。

これはパスワードと同じように扱ってください。 他人に公開したり、SNSなどに貼り付けたりしないでください。

4. Gyazo Inboxを連携に共有する

Notion APIからデータベースへ書き込めるように、 「Gyazo Inbox」を作成したIntegrationに共有します。

  1. 「Gyazo Inbox」を開く
  2. 右上の「•••」をタップ
  3. Connectionsを開く
  4. 作成した「Gyazo Shortcut」を追加
ここは忘れやすいポイントです。

Integrationを作っただけでは、Notionのデータベースへアクセスできません。 必ず「Gyazo Inbox」をIntegrationに共有してください。

5. NotionのデータベースIDを確認する

「Gyazo Inbox」のURLを確認します。 

https://www.notion.so/xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx?v=yyyy

長い英数字部分がIDになります。

現在のNotion APIでは、 DatabaseとData Sourceの扱いが分かれている部分があります。

実際のAPI設定では、使用しているNotion環境に合わせて Data Source IDなどを確認する必要があります。

6. iPhoneのショートカットを作る

1
iPhoneのショートカットアプリを開きます。
2
右上の＋をタップします。
3
ショートカット名を 📸 Gyazo → Notion にします。

7. 共有シートから実行できるようにする

ショートカットの詳細設定で、 「共有シートに表示」 をONにします。

受け取る入力としてURLを設定します。

完成するとこうなります。

Gyazoで画像を撮影
        ↓
共有
        ↓
「Gyazo → Notion」
        ↓
Notionへ登録

8. Gyazo URLを受け取る

ショートカットの入力として、 GyazoのURLを受け取ります。 

ショートカット入力
        ↓
Gyazo URL

例えば、 

https://gyazo.com/xxxxxxxxxxxxxxxxxxxxxxxx

のようなURLです。

9. Gyazo APIから画像情報を取得する

Gyazoには公式APIがあり、画像情報を取得できます。

取得できる情報には、例えば以下があります。

  • 画像ID
  • GyazoページURL
  • 画像URL
  • サムネイルURL
  • 撮影関連情報

重要なのは、 GyazoのページURLから、画像そのもののURLを取得する ことです。 

GyazoページURL
      ↓
Gyazo API
      ↓
画像URL
      ↓
https://i.gyazo.com/xxxxxxxx.png

10. Notion APIに送信する

iPhoneショートカットの 「URLの内容を取得」 アクションを使います。

送信先：

https://api.notion.com/v1/pages

メソッド：

POST

ヘッダー

Authorization: Bearer YOUR_NOTION_SECRET
Notion-Version: 2026-03-11
Content-Type: application/json
注意：

YOUR_NOTION_SECRETは、 実際にNotionで発行したIntegration Secretに置き換えます。

11. Notionへ送るJSON

Notion APIには、 「これは画像ブロックです」と指定して送ります。 

{
  "parent": {
    "data_source_id": "あなたのデータソースID"
  },
  "properties": {
    "名前": {
      "title": [
        {
          "text": {
            "content": "Gyazo画像"
          }
        }
      ]
    }
  },
  "children": [
    {
      "object": "block",
      "type": "image",
      "image": {
        "type": "external",
        "external": {
          "url": "Gyazoの画像URL"
        }
      }
    }
  ]
}

ここが最大のポイント

単純に、 

https://gyazo.com/xxxxx

というリンクを貼るのではありません。

Notion APIにimageブロックとして登録します。

12. Notionでどう見えるか

📸 Gyazo画像 2026-10-03 19:52

🖼️ Gyazoの画像がここに表示されます

🔗 Gyazoで開く

📅 2026/10/03 19:52

🏷 未整理

13. さらに便利にする

ショートカットからNotionへ登録するときに、 画像だけでなく追加情報も一緒に登録できます。

情報 用途
画像 スクリーンショット本体
Gyazo URL 元のGyazoページを開く
撮影日時 いつ保存したか確認
ステータス 未整理・保存・不要など
メモ 自分のコメント
OCR 画像内の文字を検索・AI分析

17. Notion側に画像そのものを保存する方法

現在のNotion APIには File Upload API もあります。

そのため、将来的には、 

Gyazo画像
    ↓
画像データ取得
    ↓
Notion File Upload API
    ↓
Notionにファイルとして保存
    ↓
Notion画像ブロックに添付

という構成にもできます。

おすすめの進め方

  1. まず「Gyazo URL → Notion画像表示」を作る
  2. 正常に動いたらOCRを追加する
  3. その後、必要ならNotionへの画像ファイル保存に進む
  4. 最後にAIによる自動分類・要約を追加する

最初から全部自動化するより、 小さく作って動作確認しながら拡張する 方が失敗しにくいです。
