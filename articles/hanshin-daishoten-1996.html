ナリタブライアン vs マヤノトップガン — 伝説の一騎打ちを騎手はどう語ったか

GII 芝3000m 阪神 年度代表馬対決 10頭立て

結果： 1着 ナリタブライアン（武豊） 3:04.9 ／ 2着 マヤノトップガン（田原成貴） アタマ差 ／ 3着 ルイボスゴールド 9馬身差

前年三冠馬・94年年度代表馬ナリタブライアンと、前年菊花賞・有馬記念を連勝した95年年度代表馬マヤノトップガン。ともにブライアンズタイム産駒。年度代表馬同士の直接対決は1985年天皇賞・春のシンボリルドルフ vs ミスターシービー以来11年ぶり。スローペース（1000m 63.0秒）からの3コーナーでのマヤノのロングスパートにブライアンが追従、約400mのマッチレースになった。

1. 武豊（ナリタブライアン）の語り

レース直後

武豊：「ゴールした瞬間、鳥肌が立った」

勝利後のウィナーズサークルではGIIでは異例の「ユタカ」コール。自身も興奮を隠せないコメントを残した。ブライアンの復活劇と、2頭だけが抜け出した異常な展開に対する素直な感情だった。

出典：第44回阪神大賞典 Wikipedia / Number Web 脚注

後日の冷静な回顧

武豊：「勝つには勝ったが、あれっという感じもした。あの馬の全盛期はあんなものではなかったし、本当のブライアンの姿をもう一度僕が呼び戻せればと思っていたのだが」

武豊はこの勝利を手放しでは喜んでいない。三冠を獲った時のように、ゴーサインで後続を千切る圧倒的な強さは見られず、接戦に持ち込まれたことへの違和感を語っている。自身にとっては「復活の第一歩」だが「完全復活ではない」という認識だった。

武豊の視点は一貫して 「ブライアンという馬へのリスペクト」 にある。勝ってもなお「本当のブライアン」を呼び戻したいという思いが強く、だからこそ鳥肌と同時に「あれっ」という複雑さが同居した。

2. 田原成貴（マヤノトップガン）の語り

田原はこのレースについて、時期・媒体によって3つの異なるトーンで語っている。いずれも天才ジョッキーらしい厳しさが特徴。

① クールな評価 — 「名勝負ではない」

田原成貴：「あくまでも天皇賞（春）の前哨戦であり、7,8分の仕上がりで叩きあったところで名勝負とはいえない。上がりだけのレース」
出典：月刊「おもしろ競馬塾」田原成貴エッセイ / Wikipedia 第44回阪神大賞典

② ブライアンへの畏怖 — 「本調子なら吹っ飛ばされていた」

田原成貴：「もしブライアンが本調子であれば、トップガンはスタンドまで吹っ飛ばされていたよ」

武豊同様、ナリタブライアンの全盛期の破壊力を知る田原ならではの言葉。トップガンが現役最強だった時期でも、ブライアンの絶対値への畏れがあった。

出典：同上

③ 騎手としての後悔 — 「消したい過去」

田原成貴：「みんな伝説のマッチレースとかいって今でも取り上げてくれるけど、僕にとっては消したい過去なんだ。ほんの少し、ひと呼吸だけ仕掛けが早かったんだ。ひと呼吸待てば勝っていた。ふた呼吸待てばクビ差で勝っていたよ。あのレースは覚醒剤より後悔しているね(笑い)。」

2020年 東京スポーツのインタビューで語った言葉。スローで仕掛け所が難しかった中、3コーナーからのロングスパートのタイミングが「一呼吸早かった」という自己分析。勝負師としての悔いが、伝説として美化されることへの照れ隠しと共に語られている。

出典：東スポ 2020/12/17「元天才ジョッキー・田原成貴が沈黙破り…」 / Wikipedia
田原成貴 YouTube「田原成貴、語る。第25話 伝説のマッチレース」

自身のチャンネルで改めて当時の位置取り、ブライアンをマークしていた武豊との駆け引き、ゴール前の手応えを詳細に解説。ファンから「マヤノが誘った」レースという見方に対し、自身の仕掛けが早かったという反省を動画でも繰り返している。

3. 二人の語りの対比

観点武豊田原成貴
レースの評価感情的・鳥肌が立つほどの名勝負と直後は評価。後に冷静に「全盛期ではない」と修正冷静・「前哨戦で7、8分」「名勝負ではない」と一貫してクール
勝敗の要因ブライアンの地力で拾った勝利。自分が本来の姿を呼び戻せなかった悔い自分の仕掛けが一呼吸早かったことが敗因。待てば勝てたという自責
相手馬への評価ブライアンへの絶対的な信頼と愛着「本調子のブライアンなら吹っ飛ばされる」畏怖。トップガンの限界も認識

4. 第三者の視点（補足）

競馬評論家・大川慶次郎は「ブライアンの本領は騎手がゴーサインを出すと並外れた集中力で他馬を大きく引き離す点にある。それができなかったがために接戦となったレースを名勝負というのはナリタブライアンを知らない人だ」と評した。つまり、接戦＝名勝負ではなく、ブライアンの不完全さが生んだ接戦だったという厳しい見方もある。
